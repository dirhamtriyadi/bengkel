# Flow Transaksi Midtrans

Dokumen ini disiapkan untuk memenuhi permintaan onboarding Midtrans mengenai **Flow Transaksi dalam format PDF**, khususnya customer journey dari membuka website/aplikasi sampai masuk ke halaman pembayaran.

Artefak final:

- `Midtrans-Flow-Transaksi-BengkelOS.pdf` — PDF A4, 5 halaman.
- `source/*.svg` — sumber visual setiap halaman agar identitas merchant, URL, atau isi flow dapat diperbarui tanpa mengedit PDF secara langsung.

Flow yang didokumentasikan mencakup transaksi servis motor dan pembelian retail. Keduanya bertemu pada review tagihan, pemilihan metode Midtrans, pembuatan Snap token, pembukaan payment page, serta konfirmasi pembayaran dan receipt.

Mockup layar pada dokumen merepresentasikan UI dan integrasi yang diimplementasikan dalam BengkelOS. Dokumen tidak memuat Server Key, Client Key, token transaksi, data kartu, OTP, atau kredensial pelanggan.
